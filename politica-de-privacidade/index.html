Política de privacidade

Última atualização: [DATA]

Resumo em linguagem simples

  • O formulário solicita os dados necessários para combinar o pedido e a entrega pelo WhatsApp. Ele não salva esses dados no site.
  • O Supabase recebe os dados da conta para cadastro e login. Não vendemos nem alugamos seus dados.
  • Escreva para [E-MAIL DE CONTATO] para solicitar acesso, correção ou exclusão dos seus dados, conforme a lei.

1. Quem trata seus dados

[NOME DO RESPONSÁVEL] é responsável pelo tratamento dos seus dados na TapLocal. Escreva para [E-MAIL DE CONTATO] para falar sobre seus dados pessoais.

2. Dados coletados

O formulário de pedido solicita nome completo, WhatsApp, nome da empresa, cidade e bairro, perfil do Instagram quando necessário e observações opcionais. Também solicita CEP, rua, número, complemento, bairro, cidade e estado para a entrega. Ao criar uma conta, você informa nome, e-mail e senha ao serviço de autenticação Supabase. O formulário de pedido não solicita dados de pagamento.

3. Finalidades

Usamos os dados enviados pelo WhatsApp para combinar o pedido, o pagamento e a entrega, além de atender dúvidas, reclamações, trocas e devoluções. Usamos os dados da conta para cadastro, login, confirmação de e-mail e recuperação de senha. O site não envia e-mails de status de pedidos nem mantém registros de pedidos em um banco de dados.

4. Compartilhamento

Quando você envia o pedido, os dados preenchidos são incluídos na mensagem aberta no WhatsApp para a TapLocal. Os dados de cadastro e login são enviados ao Supabase para autenticação. Não vendemos nem alugamos seus dados. Ainda precisamos confirmar quem recebe os dados para despachar as placas: [CONFIRMAR: quem despacha as placas].

5. Tempo de guarda

O formulário de pedido não salva os dados preenchidos no site. Os dados enviados pelo WhatsApp e os dados da conta são tratados nos respectivos serviços. Ainda precisamos confirmar os prazos de retenção e os procedimentos de exclusão: [CONFIRMAR: retenção e exclusão dos dados].

6. Direitos do titular (LGPD)

Você pode solicitar confirmação do tratamento, acesso, correção e os demais direitos previstos na Lei Geral de Proteção de Dados (LGPD), incluindo exclusão quando aplicável. Escreva para [E-MAIL DE CONTATO] e explique o que deseja solicitar. Respondemos no prazo previsto em lei.

7. Segurança

Adotamos medidas técnicas para proteger seus dados.

8. Cookies e armazenamento no navegador

O login mantém você conectado. Se a opção "Lembrar de mim" estiver marcada, a sessão fica guardada no armazenamento local do seu navegador até você sair. Se ela estiver desmarcada, a sessão é apagada quando você fecha o navegador. Você pode apagar esses dados a qualquer momento nas configurações do navegador.

9. Menores

O site é destinado a maiores de 18 anos ou empresas. Se souber que um menor enviou dados, escreva para [E-MAIL DE CONTATO] para solicitar a análise e a exclusão quando aplicável.

10. Alterações

A versão em vigor é a publicada nesta página. Consulte a data de atualização para verificar quando o texto foi revisado.
